# Photo Gallery Website

A responsive photo gallery website built with HTML, CSS, and JavaScript.

The project focuses on visual presentation, smooth scrolling, and scroll-based animations using GSAP, ScrollTrigger, and Locomotive Scroll.

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Smooth scrolling experience
- Scroll-based animations
- Interactive image sections
- GSAP animations
- GSAP ScrollTrigger effects
- Locomotive Scroll integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Locomotive Scroll

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktop, tablet, and mobile devices.

## 🎬 Animations & Scrolling

GSAP is used to create animations throughout the website.

ScrollTrigger controls animations based on the user's scroll position.

Locomotive Scroll is used to create a smooth scrolling experience.
